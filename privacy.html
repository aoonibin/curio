개인정보처리방침

앱: 큐리오 업로드 (Curio Uploader) · 시행일: 2026년 10월 17일 · 큐리오 홈

큐리오 업로드는 유튜브 채널 큐리오(@curiokrtv) 운영자가 자기 컴퓨터에서 자기 채널에 영상을 올리려고 만든 개인용 프로그램입니다. 운영자 본인만 사용하며, 다른 사람이 로그인하거나 다른 사람의 정보를 다루지 않습니다.

1. 사용하는 Google 사용자 데이터

운영자가 직접 로그인해 허락한 범위에서 YouTube Data API를 다음 목적으로만 사용합니다.

  • youtube.upload: 운영자 채널에 영상, 제목, 설명, 썸네일을 올립니다.
  • youtube.force-ssl: 운영자 채널 이름을 확인하고, 운영자가 올린 영상에 계산 근거 댓글을 답니다.

2. 저장과 보관

  • 로그인 결과로 받는 접근 토큰은 운영자 컴퓨터에만 파일로 저장합니다. 별도 서버로 보내지 않습니다.
  • 업로드한 영상 주소와 시각은 운영자 컴퓨터의 기록 파일에만 남깁니다.
  • 토큰 파일을 지우거나 아래 방법으로 권한을 철회하면 더 이상 접근하지 않습니다.

3. 제3자 제공과 광고

Google 사용자 데이터를 판매하거나 제3자에게 제공하지 않습니다. 광고, 분석, 인공지능 학습에도 쓰지 않습니다. 큐리오 업로드가 Google API로 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 권한 철회

Google 계정 → 타사 앱 및 서비스에서 '큐리오 업로드'의 접근 권한을 언제든 삭제할 수 있습니다.

5. 변경과 문의

내용이 바뀌면 이 페이지에 시행일과 함께 알립니다. 문의는 유튜브 채널 큐리오를 통해 남겨 주세요.

English summary

Curio Uploader is a personal tool used only by the owner of the YouTube channel Curio (@curiokrtv) to upload videos to that channel from the owner's own computer. With the owner's consent it uses the YouTube Data API scopes youtube.upload (upload videos, titles, descriptions, thumbnails) and youtube.force-ssl (read the channel name and post a comment on the owner's own videos). OAuth tokens are stored only on the owner's computer and are never sent to any other server. Google user data is not sold, shared with third parties, or used for advertising, analytics or AI training. Curio Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: via the YouTube channel Curio. Effective date: October 17, 2026.
